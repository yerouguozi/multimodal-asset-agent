## 4. 完成定义（DoD）

一个阶段"完成"必须满足：

- 功能可手动演示（有截图/操作路径）；
- 新功能配有 pytest 测试且全绿（LLM/网络全 mock）；
- 关键决策与数据流已写进 docs/；
- 代码已提交（git log 清晰）。

## 5. 风险与对策

| 风险 | 对策 |
|---|---|
| SiliconFlow 某些模型不可用/限流 | 模型 ID 全部走 .env 配置；实现时逐一验证；降级兜底 |
| ffmpeg 在 Windows 上缺失 | 用 imageio-ffmpeg（pip 自带二进制）或 winget 安装 |
| 时间不够做 P1 | 严格按 P0 顺序；P1 只做最有含金量的"检索评测 + 模型路由" |
| 向量库/队列选型拖慢进度 | 先用本地实现跑通，抽象接口，后期平滑升级 |
