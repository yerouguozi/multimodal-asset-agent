# 功能设计

## 1. 功能清单

### 1.1 素材入库（P0）

- 上传：支持图片 / 视频 / 音频 / 文档（PDF、Word、Excel、TXT、MD）多文件上传；
- 自动处理（异步，界面可见进度）：
  - 校验 + SHA-256 去重（完全相同的文件只保留一份）；
  - 感知哈希（pHash）近似去重（相似图片标记提示）；
  - 生成缩略图 / 预览（图片缩略图、视频封面、音频波形占位、PDF 首页预览）；
  - 内容理解：视觉模型生成描述与标签；文档抽取文本并生成摘要；音频转写；视频抽帧 + 转写；
  - 向量化入库：所有模态统一嵌入到同一语义空间；
- 处理失败自动重试（最多 N 次，指数退避），失败原因可见。

### 1.2 跨模态检索（P0）

- 自然语言搜索：文字搜图 / 搜视频 / 搜音频 / 搜文档（"找一张有雾霾感的科技大楼夜景"）；
- 混合检索：语义向量 + 关键词（BM25）+ 元数据过滤 + 重排；
- 筛选：按类型（图/视频/音频/文档）、标签、上传时间；
- 以图搜图（P1）：上传一张参考图，检索相似素材。

### 1.3 领域画像（P0）

- 自动统计：模态占比、标签频次、高频主题、热门素材；
- 一句话总结："这个素材库目前主要是关于 X、Y、Z 的……"；
- 自适应检索加权：视频多则提升转录匹配权重，图片多则提升视觉描述权重。

### 1.4 Agent 对话（P0 搜索问答 / P1 生成与处理）

素材助理 Agent 通过工具调用完成：

| 工具 | 能力 | 优先级 |
|---|---|---|
| search_assets | 语义检索素材 | P0 |
| get_asset_detail | 查看素材详情与理解结果 | P0 |
| domain_profile | 回答"我的素材库是什么领域" | P0 |
| generate_image | 文生图，生成的新素材自动入库 | P1 |
| transform_asset | 压缩 / 裁剪 / 转格式（图片、音频、视频） | P1 |
| collection_report | 自动生成某个分类/搜索结果的合集报告 | P2 |

### 1.5 基础管理（P0 精简）

- 素材列表 / 详情 / 删除；
- 标签查看与人工修正；
- 用户注册 / 登录 / JWT（数据按用户隔离）。

### 1.6 工程能力（贯穿）

- 任务队列 + 失败重试 + 并发控制；
- 优雅降级：无 LLM Key、无向量服务时功能照常（确定性兜底）；
- 成本追踪与模型路由：简单图片走轻量模型、复杂任务走大模型；
- 检索评测：评测集 + Recall@k / MRR / NDCG 报告；
- 测试 + CI + Docker 部署。

## 2. 典型用户故事

1. **设计师**："找一张有雾霾感的科技大楼夜景" → 返回相关图片（文字搜图）。
2. **自媒体**：上传 20 段口播视频 → 自动转录 → "找出我说过『收益』的那几段"（视频内文搜索）。
3. **学生**：上传课件 PDF + 课堂录音 → "这门课主要讲了哪几个主题？"（领域画像 + 文档问答）。
4. **创作者**："基于这些产品图，生成一张 16:9 的 banner 背景"（Agent 调用文生图并入库）。

## 3. 功能优先级

- **P0（MVP 必须）**：四类素材上传与自动理解、统一检索、基础 Agent 问答、领域画像、管理界面；
- **P1（加分）**：文生图、素材处理工具、以图搜图、检索评测报告、模型路由；
- **P2（后置可选）**：自动合集/周报、MCP 暴露、Milvus 上线、多 Agent 协作。
