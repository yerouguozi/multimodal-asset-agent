# 项目概述

> 项目代号：Multimodal Asset Agent（多模态素材 Agent）
> 一句话定位：**不预设领域的多模态素材管理 Agent——上传什么素材，它就自动"长成"什么方向的素材中心。**

## 1. 要解决的问题

- 素材一多就难找：图片、视频、音频、文档散落各处，靠文件名和人工标签检索，效率低；
- 人工打标成本高：为大量素材写描述、打标签、做摘要，耗时且不一致；
- 文本 Agent 的盲区：现有 RAG/Agent 项目只能处理文字，看不见图片内容、听不懂视频和音频；
- 现有素材库都是"死库"：只存不思考，不会总结库里有什么、不会主动建议怎么用。

## 2. 核心价值主张

1. **多模态入库自动化**：上传任意素材，系统自动完成去重、预览生成、内容理解（描述/标签/OCR/转录）、统一索引；
2. **跨模态语义检索**：文字搜图、文字搜视频、文字搜音频，以图搜图，搜"意思"而不是搜"文件名"；
3. **Agent 主动服务**：一个素材助理 Agent，能搜素材、生成素材（文生图）、处理素材（压缩/裁剪/转格式）、总结素材库；
4. **领域自适应**：系统不预设分类体系，标签体系和领域画像全部从已入库素材中自动浮现；同一个系统，喂不同数据，长成不同方向的应用。

## 3. 目标用户与场景

- 个人创作者：照片、灵感截图、音效、参考视频的整理与复用；
- 自媒体团队：选题配图、视频素材、BGM 的统一管理与语义检索；
- 设计师/工作室：视觉素材、UI 资源、文档的管理；
- 知识管理：课件 PDF、讲座录音、笔记的统一归档与问答。

## 4. 与非 Agent 素材库的区别

| 对比项 | 传统素材库 | 本项目 |
|---|---|---|
| 检索方式 | 文件名 + 人工标签 | 自然语言语义检索，跨模态 |
| 入库整理 | 人工分类打标 | 自动理解、打标、摘要、索引 |
| 领域适配 | 提前配置分类 | 从数据自动浮现，无需配置 |
| 能动性 | 被动存取 | Agent 主动搜索/生成/处理/建议 |

## 5. 简历定位（为什么它有含金量）

- 统一的多模态入库流水线（队列、去重、重试、并发控制）；
- 跨模态统一语义空间 + 检索策略对比实验（Recall@k / MRR / NDCG 量化）；
- 领域自适应的数据驱动设计（不写死分类，标签体系从数据长出）；
- LangGraph Agent 工具调用（搜索/生成/处理素材）；
- 复用自有 agent-qc-platform 对该 Agent 做质量评测（系统思维）；
- 工程完整度：测试、CI、Docker 部署、优雅降级、成本优化。

## 6. 非目标（明确砍掉）

- 人脸识别、说话人分离、3D 模型、超高清流媒体转码；
- 复杂的权限分级与协同审批流程（MVP 仅 JWT 登录 + 用户数据隔离）；
- 不做任何领域预设的 UI/文案（领域只由数据决定）。
