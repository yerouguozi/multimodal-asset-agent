# 用 agent-qc-platform 评测本 Agent

"用自己的基础设施测自己的新 Agent"：把本项目作为 SUT 接入你已有的 Agent 质控平台，
由平台的评测引擎（确定性检查 + LLM-as-Judge）对素材助理打分。

## 为什么能接

质控平台提供多种 `AgentDriver`。我们实现了兼容 **CustomerServiceDriver** 的会话接口
（`POST /api/sessions` → `POST /api/sessions/{id}/messages`），并由我们的 Agent 在响应中
直接上报 `tool_calls`（search_assets / generate_image / transform_asset 等），无需插桩。

## 接入步骤

### 1. 启动两个后端

```powershell
# 本 Agent（SUT），建议 8002
cd C:\Users\huiyi\project_agent\multimodal-asset-agent\backend
.\.venv\Scripts\python -m uvicorn app.main:app --port 8002

# 质控平台，端口 8000（用它的官方启动方式）
cd C:\Users\huiyi\project_agent\agent-qc-platform\backend
.\.venv\Scripts\python -m uvicorn app.main:app --port 8000
```

### 2. 注册 Agent + 建评测集 + 加用例

```powershell
cd C:\Users\huiyi\project_agent\agent-qc-platform\backend
.\.venv\Scripts\python scripts\connect_agent.py `
  --name "多模态素材Agent" `
  --chat-url http://127.0.0.1:8002 `
  --driver-type customer_service `
  --dataset "素材Agent评测集" `
  --cases C:\Users\huiyi\project_agent\multimodal-asset-agent\backend\scripts\qc_cases.json
```

说明：
- `connect_agent.py` 会自动调用我们 `/api/auth/register` 拿 token（默认 demo/demo123，密码 ≥4 位）；
- 用例格式：`[{"input_prompt": "...", "expected_behavior": "..."}, ...]`（见 scripts/qc_cases.json）。

### 3. 跑评测

平台前端刷新后，Agent 下拉选择"多模态素材Agent"，对"素材Agent评测集"发起评测运行。
评测引擎会：
- 逐用例调用我们的 `/api/sessions/{id}/messages`，拿到回答与工具调用；
- 运行确定性检查（如回答非空、工具被调用）；
- LLM-as-Judge 按正确性/事实一致性打分（平台配置 DEEPSEEK_API_KEY）。

## 注意

- 评测前先给本 Agent 的素材库传一些素材，否则检索类用例会如实回答"没有找到"；
- 本 Agent 的 JWT_SECRET 可改（backend/.env），connect_agent 的默认账号 demo/demo123 需要先注册。
